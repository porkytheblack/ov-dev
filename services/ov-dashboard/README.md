# ov-dashboard

Next.js 14 App Router. Brand-conforming — radius-zero, amber-only accent,
JetBrains Mono for data, Inter for prose. Pages:
- `/login` (+ first-boot wizard)
- `/` overview (camera grid + recent incidents)
- `/cameras/[id]` live view + recent activity
- `/cameras/[id]/setup` ROI editor, classes, scene description
- `/cameras/new` RTSP add form
- `/incidents` list grouped by day
- `/incidents/[id]` clip player + ack
- `/incidents/[id]/playback?token=` public deep-link target
- `/calendar` month view
- `/settings` subscribers + system status
- `/settings/account` password change pointer
